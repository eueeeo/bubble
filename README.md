# Bubble — сервис прачечной и химчистки

Веб-приложение сервиса прачечной и химчистки «Bubble». Клиентская часть реализована как одностраничное приложение (SPA) на Vue 3 с компонентной архитектурой и стилизацией Tailwind CSS. Серверная часть разработана на Laravel 11 с REST API, аутентификацией сессий, базой данных SQLite, админ-панелью Voyager, системой логирования и модулем обработки Excel-отчетов.

Демонстрационная версия: **[https://bubble.eouiye.workers.dev](https://bubble.eouiye.workers.dev)**

## Основные возможности

### Клиентский интерфейс (SPA)
- Главный экран с обзором услуг и быстрым переходом к тарифам
- Каталог тарифов на стирку и сушку («Базовый», «Стандарт», «Семейный»)
- Блок «Как это работает» с пошаговым процессом обслуживания
- Калькулятор и форма оформления заказа с выбором типа белья, опций и расчетом стоимости
- Список филиалов с адресами, графиком работы и индикатором загруженности
- Блок отзывов клиентов и место для партнерских материалов
- Встроенный виджет онлайн-чата службы поддержки с быстрыми ответами
- Переключение между светлой и темной темами оформления (☀ / ☾)

### Аутентификация и учетные записи
- Вход в личный кабинет по адресу электронной почты и паролю
- Регистрация новых клиентов с валидацией данных
- Функция безопасного восстановления и сброса пароля

### Администрирование и аналитика
- Панель администратора на базе Voyager (`/admin`)
- Управление заказами, статусами выполнения и пользователями
- Импорт и экспорт данных в формате Excel (`.xlsx`)
- Журналирование действий и просмотр системных логов с подсветкой различий

## Стек технологий
- **Frontend**: Vue 3, Vue Router 4, Tailwind CSS, Vite
- **Backend**: PHP 8.2+, Laravel 11, Voyager Admin, SQLite
- **Дополнительно**: Laravel Vite Plugin, Axios, PhpSpreadsheet

## Структура проекта
- `app/Http/Controllers/Api/` — API-контроллеры (авторизация, заказы, логи, импорт/экспорт Excel)
- `app/Models/` — модели Eloquent (User, Order, Log, Project)
- `database/migrations/` — миграции структуры базы данных
- `database/seeders/` — сидеры начальных данных и конфигурации Voyager
- `resources/js/` — клиентская часть на Vue 3 (компоненты, представления, маршрутизация)
- `resources/css/style.css` — стили и пользовательские директивы Tailwind CSS
- `routes/web.php` — маршруты веб-приложения и API
- `archive/pr9-10/` — материалы практических работ

## Как запустить

### Требования
- PHP >= 8.2 (с расширениями pdo_sqlite, mbstring, openssl)
- Composer
- Node.js >= 18 и npm

### Установка и запуск

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/eueeeo/bubble.git
   cd bubble
   ```

2. Установить зависимости:
   ```bash
   composer install
   npm install
   ```

3. Настроить окружение:
   ```bash
   cp .env.example .env
   php artisan key:generate
   ```

4. Подготовить базу данных и применить миграции с сидерами:
   ```bash
   touch database/database.sqlite
   php artisan migrate --seed
   ```

5. Собрать фронтенд:
   ```bash
   npm run build
   ```

6. Запустить локальный сервер:
   ```bash
   php artisan serve
   ```
   Приложение будет доступно по адресу: `http://127.0.0.1:8000`

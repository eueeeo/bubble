# Bubble

Веб-приложение сервиса прачечной и химчистки. Клиентская часть реализована как одностраничное приложение (SPA) на Vue 3 и Tailwind CSS, серверная часть — на Laravel 11 с REST API, базой данных SQLite, панелью администратора Voyager и модулем экспорта отчетов в Excel.

Демонстрационная версия: **[bubble.eouiye.workers.dev](https://bubble.eouiye.workers.dev)**

## Основные возможности

### Клиентский интерфейс (SPA)
- Каталог услуг и тарифов на стирку и химчистку («Базовый», «Стандарт», «Семейный»)
- Интерактивный калькулятор стоимости и форма оформления заказа с выбором параметров
- Личный кабинет клиента с историей заказов и статусами выполнения
- Переключение между светлой и темной темами оформления

### Аутентификация
- Регистрация новых клиентов с валидацией входных данных
- Авторизация по email и паролю
- Восстановление и сброс пароля

### Панель администратора (Voyager)
- Управление заказами, изменение статусов и просмотр деталей
- Учет пользователей и распределение прав
- Экспорт и импорт данных в формате Excel (`.xlsx`)
- Просмотр системных логов и истории действий с подсветкой различий

## Стек технологий

- **Frontend:** Vue 3, Vue Router 4, Tailwind CSS, Vite
- **Backend:** PHP 8.2+, Laravel 11, Voyager Admin, SQLite
- **Дополнительно:** Axios, PhpSpreadsheet

## Структура проекта

- `app/Http/Controllers/Api/` — контроллеры API (авторизация, заказы, логи, экспорт Excel)
- `app/Models/` — модели Eloquent (User, Order, Log, Project)
- `database/migrations/` — миграции структуры таблиц SQLite
- `database/seeders/` — сидеры начальных данных и конфигурация Voyager
- `resources/js/` — компоненты, представления и маршрутизация Vue 3
- `resources/css/style.css` — стили и директивы Tailwind CSS
- `routes/web.php` — маршруты приложения и API

## Установка и запуск

Для работы требуются PHP 8.2+, Composer и Node.js.

1. **Клонировать репозиторий:**
   ```bash
   git clone https://github.com/eueeeo/bubble.git
   cd bubble
   ```

2. **Установить зависимости:**
   ```bash
   composer install
   npm install
   ```

3. **Настроить окружение и базу данных:**
   ```bash
   cp .env.example .env
   php artisan key:generate
   php artisan migrate --seed
   ```

4. **Собрать фронтенд:**
   ```bash
   npm run build
   ```

5. **Запустить локальный сервер:**
   ```bash
   php artisan serve
   ```
   Приложение откроется по адресу `http://127.0.0.1:8000`. Панель администратора доступна по адресу `/admin`.
